## 🔒 Reporting a Vulnerability

The SwarmProof team takes verification security and sandbox integrity very seriously. If you discover a vulnerability or security bypass (such as a method to spoof execution receipts, bypass AST anti-weakening guards, or execute arbitrary shell injection through test runner harnesses):

1. **Do NOT file a public issue.**
2. Please report your findings privately to **dev@growthwebdev.com** with the subject `[SECURITY] SwarmProof Vulnerability Report`.
3. Include detailed reproduction steps, proof-of-concept payload, and the affected version.
4. We will acknowledge receipt within 24 hours and provide a remediation patch.
